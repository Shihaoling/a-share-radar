# 资讯全文、MiniMax 与走势来源

生产任务全部在 GitHub Actions。MINIMAX_API_KEY 只从 Actions secret 注入，代码、网页与日志不保存密钥；用户提供的 key id 不是接口必填参数，不当成 GroupId 使用。

## 正文与摘要

每天北京时间 09:00–16:00 每半小时更新，GitHub 定时调度可能延迟。先使用 Tushare 可用的资讯清单，缺失后补充公开来源，再访问原文 HTML 提取正文。只读取公开正文，robots 无法核验、拒绝访问、验证码、付费墙、登录墙时停止；不绕过限制、不多次点击。每轮最多 20 篇、每主机最多 3 篇、36 个 HTTP 请求、100 秒；同源间隔至少 4 秒，失败主机至少冷却 30 分钟，通常 24 小时。每个 URL 完成后复用正文缓存，不重复下载；重定向最多两次且重新验证公网地址与 robots。

finance.eastmoney.com 的旧 HTTP 文章链接先升级为同路径 HTTPS，再检查 robots 与采集；已用一次真实文章访问验证。正文不按摘要长度截断，保存全文、哈希、来源、提取方法和实际取得时间到 data/news_content/cache.json，并和分析版本归档到 data/news_archive。无法取得正文时显式标记，不能将标题或摘要当作全文。前端数据不重复携带整篇正文，以保证加载速度，保留原文链接。

按当前官方文档选择最新高能力 MiniMax-M3.1-Flash，reasoning_effort=max，通过官方中国区 HTTPS 地址调用。每轮最多 16 篇、600 秒；超出预算下轮增量处理。完整提取正文送入模型（超过 25 万字符显式暂缓，不偷偷裁剪）。每条资讯输出醒目但简约的一至两句摘要，逐个 SW2021 一级行业给出 positive/negative/mixed/neutral/unknown、时间范围、传导依据、原文逐字引文；宏观影响另判。摘要在每条资讯开头，证据折叠展开。

提示词保存在 pipeline/minimax_news.py 的 system_prompt，规定材料中的指令不得执行，区分事实/计划/观点/传言，区分上游受益与下游成本，不将单家公司推广到整个行业，不把经营影响当股票涨跌。正文按原顺序无损划为带编号片段，模型只选引用编号，程序还原原文，避免模型改写引文；v1已校验成功的历史分析继续复用。返回结果必须通过行业代码/名称、标签、数值范围和原文引文校验（只容许排版空白差异，存回原文实际片段，不接受改写）。缓存键包含正文哈希、标题、模型和提示版本；保存实际分析完成时间、用量，不保存思考过程和原始错误响应。鉴权、额度和网络失败熔断，不连续重试；单篇结构或引文校验失败会单独延后，不能阻塞其他资讯。错误响应只保留固定类别与数字错误码，不保存原始内容。

每个板块独立聚合自己的方向。新增行业影响通过 signal_kind=industry_impact_v1 单独进入分类模型特征，旧版词典/FinBERT 文章语气不混入这一训练信号。保留实际可用时间，不能回填到发表日。仍需至少 30 个有成熟标签的资讯日期，且通过价格模型对照选择后，才能影响收盘涨跌概率；LLM 的自评确定度不是上涨概率。

## 总览和 Tushare

点击总览的行业色块直接切换走势图和选中状态。申万行业与东财盘中参考可分别切换，不按相同名称拼接不同编制口径。申万分时尚无数据时先显示同一指数的日线并明确说明；数据到达后，处于“今日走势”模式的图表自动显示实际分时。

官方详细文档：
- index_daily：https://tushare.pro/document/2?doc_id=95，通常约 18 点，部分指数次日下午。权限总表的 15–17 点与此不同，以具体端点返回为准。
- sw_daily：https://tushare.pro/document/2?doc_id=327，交易日 18:30 更新。
- sw_mins：https://tushare.pro/document/2?doc_id=469，每日 19:00–20:00 更新，单独权限。
- idx_mins：https://tushare.pro/document/2?doc_id=419，单独权限，文档未承诺统一具体更新时间。
- MiniMax：https://platform.minimax.cn/docs/guides/text-generation 及 /docs/api-reference/text-openai-api。

收盘补数安排北京时间 18:40、20:10/25/40/55，21:17 常规任务再补。分钟数据每轮最多 12 次请求，按尚未完成的同日同代码轮转。权限拒绝按返回冷却；不可用时保留现有来源，不制造分时点。前端只对同一代码、同一交易日优先显示 Tushare 分钟数据，原始观察点仍留档。当前配置的 Tushare 兼容主服务为 t.xiaodefa.top，官方文档的发布时间不能当作该兼容服务的保证。

## 验证

离线测试覆盖正文末段保留、导航去除、付费/验证码拒绝、正文去重、同主机冷却、密钥不入缓存、结构和引文校验、相反行业影响、未知指数影响、正文变化失效、实际可用时间、全文留档但浏览器瘦身、分钟发布时间/身份校验、摘要顺序、总览点击和同日来源替换。上线后 fulltext-report.json 记录真实采集和模型调用结果；合成连通性样本不会出现在真实资讯中，也不当作模型准确率测试。
