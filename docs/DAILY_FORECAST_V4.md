# 整体指数与板块：日频模型研究、特征工程与追加两轮优化

日期：2026-11-17（北京时间）。本版按用户要求，完成初始训练与一轮优化后，再追加两轮针对性优化；先以小批量特征实验筛选思路，再跑完整指数／板块开发验证。MAE目标为 **0.1个百分点**，达不到时部署开发验证中保留的最好版本，明确展示未达标。

当前导出模型：`daily-v4-20261116T170316Z`，训练标签截止 `2026-11-16`。**37个对象均未达到0.1；不能称为已验证可靠的预测器。** 指数保留零收益基线，板块数值采用去ER特征并对训练标签稳健截尾的Ridge，板块排序保留开发表现最好的LightGBM。概率与条件收益区间未拟合，不把排序分数或涨幅符号当成上涨概率。

## 预测对象、数据与评价

主目标为最近完成交易日T收盘后，预测下一交易日T+1：

`next_close_return_pct = 100 * (close[T+1] / close[T] - 1)`

对象为6个真实宽基指数和31个申万一级行业指数；个股、旧下次开盘预测保留为辅助。指数价格收益使用指数收盘比值，并非个股供应商pre_close标签或含分红总收益。板块相对沪深300涨幅与独立排序得分分列。

缓存中宽基各666条（2024-02-19至2026-11-16），行业各209条（2026-01-05至2026-11-16）。按上交所公告补核2024/2025日历后，20日预热形成宽基645个标签日、3870条样本；行业188个标签日、5828条样本。31个行业同一天的样本不是31个独立时间样本。

日MAE先对同一天的对象等权平均，再对日期等权平均；指数组和行业组分别报告，不用股票数量或行业数量压过另一主任务。每个对象另报MAE。RankIC逐日按行业横截面计算，同分取平均秩，常数预测的相关记缺失并报告有效覆盖。MAE单位始终为百分点，评估标签未裁剪，没有为满足0.1而缩放误差。

历史OHLC仅作“当日收盘后可得”的研究假设，并非真实到达日志。跨供应商或成交量单位切换的量额比标为缺失，避免人为百倍跳变。没有回填当前成分股、旧日估值或今天首次观察的新闻。

## 小批量特征重要性与特征工程

在6个指数与银行、电子、有色金属、医药生物、公用事业5个固定行业上，先完成32次轻量拟合。训练2026-02-03至05-11共60日，隔开05-12，验证05-13至06-02共15日，早于正式45日开发窗口2026-08-10的起点。训练为360条指数／300条行业，验证为90条／75条。

比较完整特征及去除多周期、ER趋势效率、量额、市场相对、行业状态等特征组的消融；另做同步5日块置换重要性。两种诊断分别记录，未用旧末20日选特征。去市场相对组的四组比较均变差；去ER平均仅改善约0.0055个百分点且不同模型不一致，不能断言ER普遍无效。因此完整77列和去ER的74列一并进入正式对照，最终由完整开发验证决定。

## 实际训练与两轮优化

初始V3完成140次拟合，含一轮状态特征、正则与树收缩优化；小批量特征诊断32次；本次用户追加的V4两轮实际完成146次拟合。共318次研究拟合，不包含自动化测试中的合成小模型。

全程按整日分组、训练标签早于评估首日；用同样45个开发日公平比较。旧V3候选作为保底，逐折重新拟合，未把全历史部署权重倒用于过去。每轮计划、候选、源数据／源码指纹先保存，再执行拟合。

## 主要方法与资料来源

本地知识库重点核对了行业涨跌广度、行业残差动量、AK趋势效率、市场一致性、RSRS等资料。周/月持有期只提供候选特征启发，不冒充日频效果；中心“前后各10日”窗口未作为实时输入。

- [Qlib信号与组合评价](https://qlib.readthedocs.io/en/stable/component/report.html)：数值误差、RankIC与含成本组合评价是不同任务。
- [sklearn评价指标](https://scikit-learn.org/stable/modules/model_evaluation.html)：绝对误差对应条件中位数。
- [sklearn时序验证](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)：按时间顺序隔开训练与后续评估。
- [LightGBM参数](https://lightgbm.readthedocs.io/en/stable/Parameters.html)：L1损失及排序模型参数对照，本机实际版本4.6.0。
- [上交所2024年休市公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20231226_5733939.shtml)与[2025年公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20241223_10767108.shtml)。
