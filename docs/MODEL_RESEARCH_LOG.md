# 模型实验记录与阶段性总结（V1—V4）

文档版本：1.0  
整理日期：2026-11-17（北京时间）  
适用项目：观澜 · 中国 A 股研究工作台

本记录整理已经实际完成的训练、特征工程、验证与部署，并区分事实、解释和后续假设。实验数据截止2026-11-16；部署核验快照为2026-11-17凌晨。后续新交易日的成绩须另行结算，不能从这些历史结果推定。

## 1. 当前结论

**已经完成模型工程闭环，但尚未证明有稳定的日频预测能力。**

用户当前主要需求是每天预测整体指数和板块，个股其次。现行主目标是收盘后预测下一交易日收盘涨跌幅，并单独输出板块相对大盘的强弱排序。没有因为周/月频资料较多而改变这一日期限。

| 当前项目 | 记录 |
| --- | --- |
| 已部署模型 | daily-v4-20261116T170316Z |
| 预测对象 | 6个宽基指数、31个申万一级行业指数 |
| 数值目标 | 下一交易日收盘相对当前收盘的价格收益率 |
| 指数最优保留方案 | 零收益基线，复杂候选在开发比较中未胜出 |
| 板块数值方案 | 去ER特征、训练标签5%/95%截尾的Ridge |
| 板块排序方案 | 开发阶段选出的L1 LightGBM，独立于数值模型 |
| 重复20日参考MAE | 指数1.896453、板块1.527043个百分点 |
| 排序日均RankIC | −0.057593，有效20/20日，不能称已验证有效 |
| MAE≤0.1个百分点 | 0/37个对象达到 |
| 发布依据 | 用户明确授权未达目标时发布开发验证保留的最好版本 |

“已部署”表示模型已被网站加载，不表示已达到0.1要求，也不表示已有可交易超额收益。指数输出0%是当前基线选择，不能解释为明天必定不涨不跌。

## 2. 预测与评价口径

### 2.1 一日期限没有改变

对已经完成的交易日T：

~~~text
指数／行业数值标签：
r[T+1] = 100 × (close[T+1] / close[T] − 1)

板块相对市场标签：
excess[s,T+1] = r[s,T+1] − r[沪深300,T+1]

MAE = 平均 |预测收益率 − 实际收益率|
~~~ 

收益率用百分数数值表示，MAE单位为**百分点**。预测+0.6%、实际+1.0%，误差为0.4个百分点。MAE降低4%指相对误差减少，不是收益率，也不是准确率增加4个百分点。

当前一日行情预测并不等同于一日可交易收益。若以后研究交易策略，需要另行对齐信号、成交、持有与成本，不应直接把预测标签收益当作实际利润。

### 2.2 不同目标需要不同指标

| 任务 | 主评价 | 不能替代它的量 |
| --- | --- | --- |
| 单个指数下一日绝对涨幅 | 按日期的MAE、RMSE，与Zero/训练中位数/Ridge比较 | 板块RankIC、个股样本数 |
| 行业下一日绝对涨幅 | 先日内行业等权，再日期等权的MAE，并列各行业误差 | 只报告最好行业 |
| 同日行业相对强弱 | 逐日RankIC、有效覆盖，与简单动量/反转比较 | 只看回归MAE |
| 上涨概率（尚未拟合） | Brier分数、时序校准，与训练期上涨频率比较 | 回归预测为正、情绪模型置信度 |
| 收益区间（新主任务尚未拟合） | 覆盖率与区间宽度并报 | 单独报告一个很宽的区间 |

对所有行业减去同一个市场收益，不改变当日行业排名。超额收益标签明确了经济含义，**仅换标签本身不会自动提高排序能力**。

指数组和板块组分别选模、分别报告，不把31个行业与6个指数混成一个容易掩盖差异的总分。同分采用平均秩；预测全相同时RankIC记缺失，不能按代码硬排出“强弱”。

## 3. 模型版本与实验演进

V1—V4是本记录用于梳理研究阶段的名称；实际运行ID、发布ID另行保留。

| 阶段 | 对象／目标 | 实际尝试 | 主要发现 | 当时状态 |
| --- | --- | --- | --- | --- |
| V1：神经网络本机训练 | 个股次日开盘、收盘 | 3组GRU/TCN配置、固定权重集成，RTX3070训练 | 最终确认未超过原基线门槛；重现训练轨迹有差异 | 未上传该神经模型 |
| V2：逐目标树模型研究 | 个股次日开盘、收盘 | 中位数基线，L1/L2树，24/80/101列特征，40次预定拟合 | 开盘开发MAE改善约4.10%，收盘无稳定改善 | 保留研究资产与前向预测，未部署该研究包 |
| V3：转向直接指数／板块 | 指数、行业次日收盘；行业排序 | 补核日历，基线/Ridge/L1树，140次拟合，含首轮优化 | 指数仍是Zero；板块Ridge略优；排序参考段不佳 | 保留为V4对照 |
| 特征小批试验 | 6指数＋5个固定代表行业 | 早期60日训练、隔1日、15日验证，32次拟合 | 市场相对特征值得保留；去ER仅是探索候选 | 先筛思路，再进入完整开发比较 |
| V4：用户追加两轮 | 与V3相同的指数／板块任务 | 近期训练窗、L1线性、特征掩码、收缩、组合、训练段截尾、LambdaRank，共146次拟合 | 板块开发误差继续小幅下降，指数与排序未获替换理由 | 最好保留版本已上线 |

**不能把这些行的MAE首尾相减，作为统一模型的累计进步。** 个股开盘、个股收盘与行业收盘，预测对象、日期、标签口径和样本权重都不同。V3与V4的同任务、同日期比较才具有直接可比性。

### 3.1 V1：增加模型容量没有解决问题

V1使用60日×8维量价序列，实际包含480个时序输入，不能只凭“8维”认定模型没有足够信息。180个交易日归档中，5,552只股票形成有效样本；固定候选为hidden=64、GRU75%＋TCN25%。

MAE单位：百分点。下面是最终确认段，不是后续板块任务的分数：

| 目标 | 最终候选 | 最佳基线 | 结论 |
| --- | ---: | ---: | --- |
| 个股次日开盘 | 0.996785 | 0.982670 | 更差 |
| 个股次日收盘 | 2.671164 | 2.604361 | 更差 |

当时要求验证／确认、开盘／收盘四项都优于最佳基线超过2%，最终四项均未通过，因此没有上传该神经模型。这个旧结论保留，没有因后来发布规则变化而改写。

工程上，CUDA固定种子未保证重现一致：TCN在调优阶段运行11轮，最终重现运行5轮。由此得到的可执行教训是：**保存并评估被选中的实际资产；若部署阶段重新拟合，应单列其权重和哈希。** 不能拿调优时的成绩给另一份权重背书。

### 3.2 V2：损失对齐与逐目标选择有帮助，但收益主要在开盘

V2加入训练中位数、L1树模型和多周期统计，开盘、收盘独立拟合与选择。在同样45个开发评估日、244,802条股票日样本上：

| 目标 | 最佳基线MAE | 内部验证选择流程MAE | 相对误差改善 |
| --- | ---: | ---: | ---: |
| 个股次日开盘 | 0.863734 | 0.828345 | 4.097% |
| 个股次日收盘 | 2.297205 | 2.297095 | 0.0048% |

这支持继续研究损失、正则和特征表达，不支持“加树模型就全面有效”。开盘改善也不能替代用户更关心的板块、指数收盘任务。

同容量比较中，市场状态101列没有稳定优于多周期80列，说明更多维度不自动等于更多有效信息。部分收盘选择还会产生常数预测，进一步提示数值预测和排序应分别评价。

新闻建立了可得时间归档，但当时只有一天严格覆盖、没有可信个股或宏观匹配，因此未开展历史新闻增益消融。没有把新抓到的旧闻回填成过去已经知道的信息。

## 4. 从知识库得到的启发与边界

本地知识库包括99份策略代码、62份PDF，完成索引与重点页审阅，并非声称逐字通读所有资料，也没有执行其中的交易代码。

| 资料方向 | 对本项目的启发 | 不能直接继承的部分 |
| --- | --- | --- |
| 行业动量与行业内反转 | 市场、行业、个股可分层研究 | 原月频效果不能当作日频证据 |
| 行业涨跌广度 | 检查行情是否由少数成分股推动 | 当前成员不能直接回填历史 |
| 残差动量 | 区分板块自身涨跌与相对大盘强弱 | 周频观察／持有参数需重新验证 |
| AK趋势效率、RSRS | 作为趋势或震荡状态候选 | 所需长窗口、分钟数据并不都具备 |
| 市场一致性／行业分化 | 为整体指数刻画风险状态 | 旧研究小样本不能保证当前有效 |
| 基金板块仓位测算 | 提供资金结构研究思路 | “前后各10日”的中心窗口包含未来，不能原样接入实时预测 |

原始研究更多讨论行业配置、相对强弱和组合构建，不存在必须遵循的唯一预测标签。对用户按天看走势的目的，次日收盘收益率合理；需要调整的是任务重心和验收，而不是强行改为周/月预测。

## 5. 数据与特征：先修口径，再谈复杂度

### 5.1 可见记录不等于有效训练样本

| 数据 | 可见历史 | 预热及日历核对后的一日标签 |
| --- | --- | --- |
| 6个宽基指数，每个 | 666条，2024-02-19至2026-11-16 | 645个日期，合计3,870行 |
| 31个申万行业，每个 | 209条，2026-01-05至2026-11-16 | 188个日期，合计5,828行 |

原日历只核实2026年，2024/2025年价格虽存在，却无法按原函数构成相邻交易日标签。补核官方历史日历是实际的数据修复，而非增加网络层数。

同一天的31个行业受共同市场风险影响，不能把5,828行当作5,828个独立市场日期。数据量不足主要体现在时间和市场阶段覆盖，股票或行业数量不能完全弥补。

另发现指数数据源切换时成交量单位变化。新特征要求量额比较窗口内来源和单位一致，不一致则标缺失，避免人为跳变被当成可预测信号。

### 5.2 77列不是77种独立经济信号

V3/V4完整输入为40列量价／状态及缺失标记，加37列对象身份编码，共77列。去掉5／10／20日三列ER后，最终板块输入为74列。身份编码用于区分对象，不应算作37个独立alpha因子。

候选特征包括日收益、隔夜跳空、日内收益、振幅、收盘位置；5／10／20日动量、均值、波动、上涨比例、趋势效率；量额比例及缺失标记；相对沪深300表现和行业离散度等。只使用预测时点已经完成的日线。

历史OHLC采用“该日收盘后可得”的研究假设，当前缓存不是完整的历史到达日志。估值、新闻和成员数据不能享受这一假设，必须另有实际可得时间证据。

## 6. 小批量特征工程的完整记录

### 6.1 实验设置

固定6指数，以及银行、电子、有色金属、医药生物、公用事业5个行业。使用最早共同成熟日期：

| 区段 | 日期／数量 |
| --- | --- |
| 训练 | 2026-02-03至05-11，60日；指数360行、行业300行 |
| 隔离日 | 2026-05-12 |
| 验证 | 2026-05-13至06-02，15日；指数90行、行业75行 |
| 正式开发起点 | 2026-08-10，晚于小批验证 |
| 拟合次数 | 32次，不包括置换时的重复推断 |

用Ridge和浅层L1树比较特征组消融，并做同步5日块置换。没有加载全历史已拟合模型来回测早期日期。

### 6.2 去除特征组的结果

下表取两任务×两模型的四组比较均值。ΔMAE＝去除后MAE−完整特征MAE，负数表示这次小批量比较中误差下降。

| 去除的特征组 | 平均ΔMAE（百分点） | 四组中不变差次数 | 处理 |
| --- | ---: | ---: | --- |
| 多周期5／10／20日统计 | −0.020222 | 2/4 | 有分歧，不直接大范围删除 |
| ER趋势效率 | −0.005498 | 3/4 | 作为候选，与完整输入继续比较 |
| 行业分化状态 | +0.002049 | 2/4 | 保留对照 |
| 量额特征 | +0.005144 | 2/4 | 保留对照 |
| 当日K线核心 | +0.019591 | 1/4 | 保留 |
| 市场相对特征 | +0.049313 | 0/4 | 本次不删 |

虽然去多周期组的平均改善更大，但只在2/4组不变差；按事先规则没有只追逐单个平均数。去ER在行业Ridge的小批比较中反而恶化约0.01515个百分点，因此不能据此断言ER无效。最终只将**完整77列与去ER的74列**带入后续正式开发。

### 6.3 对特征重要性的思考

去除消融回答“去掉这一组并重新训练后会怎样”；块置换回答“破坏这一组的时序关系后，固定模型误差怎样变化”。两者不是同一问题，也都不是因果证明。

重要性会受相关特征、模型容量、样本窗口和市场阶段影响。高度相关的特征可相互替代；重要性低不等于没有经济意义，训练内分裂增益高也不等于未来有效。

本次小批试验只有一个15日验证窗口和5个行业，适合缩小试验范围，不足以永久决定特征名单。完整开发中去ER方案胜出，是继续使用它的直接依据；仍不能推出跨年份普遍成立。

## 7. V3与V4：实际调优记录

### 7.1 初始直接指数／板块研究

V3完成140次拟合，包括基线、Ridge、L1树和首轮状态特征／正则／收缩对照。指数保留Zero；板块从基础Ridge的开发MAE1.124547477降到状态Ridge的1.118550754。改善小于0.1个百分点。

### 7.2 用户追加两轮

在V3之后，按明确要求再做两轮，不因第一轮改善较小而跳过第二轮。V4完成146次拟合，包含每折重新拟合旧候选、两轮新候选、参考评估和最终部署拟合。

| 阶段 | 指数开发MAE | 板块开发MAE | 板块较前阶段减少 |
| --- | ---: | ---: | ---: |
| V3保留最好 | 1.083877041 | 1.118550754 | — |
| V4第1轮 | 1.083877041 | 1.110542320 | 0.008008434 |
| V4第2轮 | 1.083877041 | 1.109963416 | 0.000578904 |

第1轮比较60／120／252日近期训练窗、L1中位数线性模型、特征掩码，并对排序尝试LambdaRank。板块数值胜出的是去ER的Ridge。

第2轮围绕保留候选比较0.25／0.5／0.75输出收缩、与训练中位数组合、仅训练段2%／98%或5%／95%分位截尾，以及排序模型正则。最终板块数值选择5%／95%训练截尾方案。**验证和参考段的真实标签均未截尾。**

各阶段都保留旧最好候选，没有为了展示“新模型”强行替换更好的基线。LambdaRank没有在开发阶段胜出，不能因为名称更贴近排序就直接上线替换。

损失与MAE对齐是提出候选的一条依据，不应代替实际对照。最终获选Ridge仍用平方损失拟合，选型指标是开发MAE；本轮L1模型未胜出，不矛盾，也不能据此宣称某种损失在所有任务上都更好。

日频指数／板块研究拟合共318次＝V3的140次＋特征小批32次＋V4的146次。V2另有40次个股研究拟合；神经网络训练轮次与这些拟合计数不是同一个概念。

## 8. 验证边界与当前误差

### 8.1 开发窗口固定，结果仍有选择偏差

正式开发使用三个完整交易日分组的15日窗口：

| 折 | 开发评估标签日 |
| --- | --- |
| 1 | 2026-08-10至08-28 |
| 2 | 2026-08-31至09-18 |
| 3 | 2026-09-21至10-19 |

每次拟合只用早于首个评估标签日的成熟标签，缩放、训练中位数和截尾分位数也只在对应训练段计算。旧候选按折重新训练，未倒用全历史部署权重。

V4反复使用这45日选择候选，因此开发最优存在选择偏差。候选留痕和时间顺序正确并不能消除多轮研究带来的乐观估计。

### 8.2 原20日不再是新的独立确认

2026-10-20至11-16共20日已经在V3读取。V4没有在代码中按该段误差选择候选，但研究者已经见过这段表现，所以这里只能称**重复历史参考**。

| 重复历史参考 | V3 | V4 | 数量 |
| --- | ---: | ---: | --- |
| 指数MAE | 1.896453223 | 1.896453223 | 20日、120行 |
| 板块MAE | 1.532458565 | 1.527042980 | 20日、620行 |
| 独立排序RankIC | −0.057593195 | −0.057593195 | 20个有效日期 |

开发MAE、重复参考MAE、将来的真实前向MAE必须分开。误差从1.532459降到1.527043只是这一段上的小幅差异，本记录没有据此声称统计显著或稳定提升。

独立排序模型的RankIC与板块数值模型自身排序相关性也不同。此处−0.057593明确指**单独选出的排序模型**，不是把所有回归模型的相关性混用。

### 8.3 0.1目标应如何理解

当前指数误差约为目标的19倍，行业约为15倍，仍有很大差距。目标没有被改写成归一化误差、准确率或挑选低波动样本后的结果。

现有试验无法证明0.1在理论上绝不可能达到，也没有证据支持在当前数据与一日任务上即将达到。继续搜索同一批历史参数，不能代替新的信息和新的验证日期。

用户后来允许“未达标也上传最好版”，改变的是发布授权，不是模型合格的事实判断。V1旧门槛失败仍然失败；V4当前未达0.1也必须如实标注。

## 9. 阶段性总结：哪些是事实，哪些只是解释

| 已观察事实 | 可以形成的判断 | 不能推出的结论 |
| --- | --- | --- |
| 指数候选未胜过Zero | 当前开发比较尚未识别出更好的指数数值信号 | 指数永远不可预测、0%必然正确 |
| 板块Ridge胜过本轮较复杂候选 | 小样本下正则与稳健性值得优先研究 | 树模型或深度学习普遍无效 |
| 去ER＋训练截尾略降MAE | 该组合值得冻结后继续观察 | ER在任何市场都应删除 |
| 市场相对特征小批去除后均变差 | 暂时保留并做跨阶段检验 | 已证明跨年份稳定有效 |
| 排序参考RankIC为负 | 当前强弱榜缺乏有效性证据 | 有100%排序覆盖就有100%准确率 |
| 加市场特征或更多列不总更好 | 应做控制容量的消融，而非只加维度 | 价格之外的信息都无用 |
| GPU重现轨迹变化 | 被选资产与部署重拟合资产需要分别存档 | 固定随机种子就能保证相同模型 |
| 误差改善已很小 | 后续应优先补信息和验证，而非无边界调参 | 多试几次就一定达到0.1 |

最值得保留的工程改进，是目标拆分、时间可得性约束、按日期验证、实际资产冻结和如实发布。它们提高了结果的可解释性与可追溯性，本身不等于提高了预测能力。

## 10. 下一阶段研究建议

以下是尚待验证的计划，不是已经取得的增益，也不在本次文档整理中自动启动新训练。

| 优先级 | 建议 | 最小检验方式 | 主要约束 |
| --- | --- | --- | --- |
| P0 | 累积真正新日期的冻结预测 | 先预定一个前向观察区间，期间不按新标签换赢家，按指数／行业分别结算 | 不能把旧确认期换名当新样本 |
| P1 | 延长真实行业历史，覆盖不同市场阶段 | 先核对官方指数版本、日期、单位和缺失，再比较更长与近期窗口 | 31×日期不等于独立日期数 |
| P2 | 重复小批特征筛选 | 多个滚动窗口重复组消融和日期块置换，检查方向稳定性 | 不按单窗重要性永久删因子 |
| P3 | 市场与板块残差分解 | 与当前直接预测并行，对绝对MAE及行业RankIC各自验收 | 预测输入不能出现下一日实际大盘 |
| P4 | 时点明确的新闻、公告和广度 | 积累足够真实可得覆盖后，一组一组消融 | 无历史成员／可得时间则不回填 |
| P5 | 真正的上涨概率与条件区间 | 独立训练、按时间校准，用Brier与覆盖／宽度验证 | 不从回归符号生成伪概率 |

### 10.1 一个值得检验的分解假设

可把行业收益拆为市场共同部分和行业剩余部分：

~~~text
r[s,T+1] = beta[s,T] × r[market,T+1] + epsilon[s,T+1]

预测时：
hat_r[s,T+1] = beta[s,T] × hat_r[market,T+1] + hat_epsilon[s,T+1]
~~~

beta只能由T及以前数据估计；下一日实际市场收益可以用于历史标签分解，不能当预测特征。如果市场预测再作为行业模型的训练输入，需要用逐期样本外预测，而非全样本拟合值。

这个结构有助于区分“大盘拖累”和“行业相对强弱”，但未必降低绝对MAE。必须保留当前直接模型与简单基线，实际比较后才能取舍。
