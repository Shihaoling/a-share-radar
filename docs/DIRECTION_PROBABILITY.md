# 收盘方向分类模型与在线资讯更新

2026-11-17。主目标从“收盘涨跌幅回归”增加为直接监督分类：目标日收盘高于、低于或等于参考日收盘。上涨概率来自训练过的分类器，不将回归正负、新闻情绪或文本分类置信度改称上涨概率。原回归模型与冻结结果保留为辅助研究。

## 已实际完成的训练

本机完成两轮研究，每轮比较13个预定配置：训练期上涨频率基线、不同正则强度的逻辑回归、浅层LightGBM分类器、近期训练窗口、缩小特征组、sigmoid校准与向训练频率收缩。指数与行业分别选择，按完整标签日划分3个15日开发窗口，随后评价固定的20日历史段。第一轮为所有非基线方案保留了校准样本；第二轮修正为仅真正需要sigmoid校准的方案保留20日，未校准方案使用全部成熟训练日期。没有将第二轮已看过的历史评价段称作新的独立确认。

价格输入为当前与多日量价、波动、行业和市场状态；对来源/单位变化保留缺失标记。新闻输入为有实际可得时间的当日语气、文章与来源数量、时间和缺失标记。历史OHLC采用当日收盘后可得假设；当前新闻不回填过去。

Brier越低越好。第二轮指数Brier变化很小，行业Brier变差；按整日做5日块自助法，差值区间均跨0。因此不能声称已验证稳定预测能力。指数120行、行业620行各只有20个市场日期，不能当成独立的120/620个市场日。概率、涨跌正确率、AUC与情绪分类置信度分别报告。

第二轮部署配置按开发Brier选出指数浅层树与行业强正则逻辑回归。云端训练会使用相同的时间隔离规则，并增加配对的“量价＋情绪 / 只用量价”候选。新版本的实际配置与评价以 `data/direction_probability/online-state.json` 指向的云端报告及线上数据为准；本表保留本机研究事实，不冒充后续云端成绩。

## 新闻情绪及训练资格

中文使用固定版本 `yiyanghkust/finbert-tone-chinese`（Apache-2.0）；英文新增固定版本 `ProsusAI/finbert`（CC-BY-NC-SA-4.0，仅适用其许可用途）。权重从模型提供方下载，使用safetensors，不启用远程自定义代码。中英文模型判断金融文本的正面/负面/中性，不直接判断中国某板块价格方向。具体模型链接和版本保留在消息记录中。

当日聚合只接纳当天已发布、已观察且未被排除的消息。过期消息可以单独显示其文本情绪，但不计入当日因子。原文标题/摘要、首次观察、实际评分时间、模型、版本、行业关联均留档；改文或换模型形成新版本，不覆盖旧记录。

目前严格可用的新闻历史过短；本机开发段拥有有效情绪的成熟日期为0。已实际做量价/量价＋可得情绪对照，两者输出相同，因此不声称学到了情绪对价格的作用。至少积累30个有已结算标签的情绪日期才允许情绪候选参与训练；满足最小数量仍需开发比较，不代表自动验证有效。不手工给正面新闻附加固定的“上涨概率加成”。

## 全部在线运行

不要求用户电脑开机。GitHub Actions执行以下任务：

- 每天北京时间09:00、09:30，依此至16:00，每半小时采集资讯、判断情绪、归档新版本并更新预测。休息日仍采资讯；交易日行情按交易日历处理。
- 盘中行情约五分钟网页采样。东方财富每轮至多一次翻页、失败冷却；资讯任务不提高行情爬取频率。
- 完整收盘日线补齐后，检查37个对象共同的成熟日期。日期未变化时不重复训练；出现新成熟标签时在云端CPU训练、调参和检验概率分类器，然后更新模型。专用 `RADAR_ALLOW_DIRECTION_TRAINING` 开关只允许这套小型分类器，不开启旧神经模型或回归训练。
- 日内新预测按半小时留存不可覆盖版本；模型和日线未更新也保留来源时间。前向评价每标的、每目标日取第一版，不把多次修订当成独立命中样本。

GitHub定时任务会排队或延迟，09:00等是目标时刻，不是到账保证。今天收盘已经发生后不补发“今天预测”；申万当日完整日线未到时等待发布，不以东方财富其他分类或ETF代替申万指数。

## 输出与复现

- `data/direction_probability/models/bundle.json`：带完整性校验的JSON模型，只含推断所需树/系数、校准和评价。
- `data/direction_probability/studies/`：预先保存的研究计划、开发选型、逐条历史评价及报告。后续 `cloud-*` 由云端实际生成。
- `data/news_archive/YYYYMMDD.json.gz`：不可覆盖的新闻/情绪版本及采集回执。
- `data/news_sentiment/`：固定版本文本推理缓存、实际推理报告和首次线上重分类请求。
- `web/data/dashboard.json`：完整预测修订台账；浏览视图只保留摘要与当前输出，避免反复下载全部台账。

本机研究入口仍可用于复现，但生产网站、采集和后续分类训练均由线上工作流执行。原始本机实验、旧模型及台账保留，网站无交易下单功能。
