# 新主数据服务与缺口补充规则

用户于2026-11-17指定 http://tus.sxdata.top/tu_share/ 为主数据服务。HTTPS握手未成功；GET会跳转到DNSPod页面，但一次不含凭证的POST返回JSON，带凭证POST已实际取得数据。程序仅POST这个固定地址，禁止重定向、代理轮换或动态端点；不把GET跳转地址当API发送目标。

凭证只从GitHub Actions Repository secret STOCK_API_TOKEN注入；使用用户给出的基础token。普通积分接口由固定白名单派生backup15000_通道；分钟、资讯和公告使用基础token。旧token必须通过一次SHA256一致性检查才能发送到新服务，避免把旧服务凭证送往新域名；校验摘要不是可调用凭证。代码、网页、日志和报告均不保存原始token。

生产接口至少6秒间隔，跨同一任务中的进程用runner临时状态共享请求间隔。HTTP429及业务code=429均识别为限流，整源至少冷却60秒；其他失败接口至少60秒后才可再次尝试。日线批处理最多一次补偿重试且至少等待60秒；明确鉴权、权限和限流错误不即时重试。任务串行执行，主源实时接口默认停用，盘中只在对应主源分钟数据缺失时使用独立网页采样。

新服务独立维护权限及冷却，不沿用旧服务拒绝记录；保留既有历史价格、原始观察、预测台账和全文归档。主源有效日线不会被后备覆盖；分钟替换要求同一代码和同一交易日。缺失的申万分钟不能拿东方财富的不同分类指数拼接。

资讯按实际成功查询的时间窗判定覆盖。主源记录去重累计，单次1500行达到上限时只确认返回数据起点之后的范围；空查询不扩大覆盖。主源已有有效资讯的时段，备用资讯保留原始归档但不在当前页面重复展示、不参与情绪和综合摘要、不额外抓正文；无主源覆盖的时间段才允许补充。接口已提供的完整资讯文本不按5000字截断，不再尝试爬取同一无URL快讯，前端标明“接口原始资讯文本”，不能冒称外部报道全文。新闻联播文字稿按日增量，日期不冒充精确发表时点。

能力报告见web/data/data-service-capabilities.json，每轮最多6个小样本，遇到失败停止该批、记录原因和下次允许时间；后续完整任务续测，不把空结果当作权限拒绝。报告只保存公开查询参数、字段、行数、固定错误类别。local样本实测见SXDATA_CAPABILITIES_20261117.json，不能将样本成功等同全历史覆盖。

切换线上后先核对仓库凭证是否与新token一致；匹配时执行一次主源更新和真实分钟回补。若不匹配，保留已发布数据并报告needs_token_update，等待用户更新后台secret，不自动泄露或转存不匹配凭证。

首次迁移先补6个大盘指数，再补申万行业；最多四个限额批次完成当日分钟回补，无新增完成项即停止。预算耗尽记为延后，不记为上游封禁。迁移时后台凭据不一致只输出needs_token_update，等待用户保存新基础token后再发起新任务。
