# 观澜 · A 股研究工作台

观澜把市场行情、板块和个股研究、快讯、公告及研报放在同一个工作台。腾讯云运行采集、分析和网站服务。GitHub 的 [腾讯云代码备份分支](https://github.com/Shihaoling/a-share-radar/tree/backup/tencent-cloud) 对应云端版本，[GitHub Pages](https://shihaoling.github.io/a-share-radar/) 提供历史静态快照。

## 网站页面

| 页面 | 内容 |
| --- | --- |
| 市场总览 | 沪深、港股和美股指数，分时及日线，行业涨跌，市场简评，经济指标日历。休市时展示最近可用分时和折叠的周度简报 |
| 趋势观察室 | 5、10、20 个交易日的累计变化和五类趋势，可分列排序。龙头放在所属板块下，独立显示走势。极端走势注明起止区间 |
| 板块雷达 | 交易所指数、申万行业及同花顺行业和热门主题。可查看成分股、行情和估值风险指标。申万官方行情未到时，标明权重股估算及覆盖 |
| A 股关联资讯 | 快讯和公告分别展示、分页及生成摘要。快讯突出上一交易日 15:00 以来的全球要闻，并提供相关来源。公告支持按公司名、股票代码和标题搜索本周记录 |
| 研报 | 按热门板块浏览或按时间分页，点击进入摘要和 PDF 阅读页 |
| 研究助手 | 结合当前页面读取本站行情、指标、资讯、公告和研报。账号聊天独立存储，访客对话限当前标签页 |
| 控制台和采集进度 | 受保护的控制台提供请求统计和模型设置。采集进度展示历史快讯采集、标注与导出的状态 |

分时和日线悬停同时显示点位或价格及涨跌幅。分时以该交易日昨收为基准，港股同样使用对应指数的昨收。图上缺失时点保留实线连接，并在悬停处显示「未采集到数据」。日夜玻璃反光随访问设备的本地时间变化，行情、快讯和日历仍使用各自标明的时区。

## 代码入口

| 目录 | 用途 |
| --- | --- |
| `web/` | 浏览器界面、详情页、研究助手组件和静态展示基线 |
| `deploy/tencent-preview/` | 腾讯云采集器、报告与分析服务、Nginx 配置和 systemd 单元 |
| `pipeline/`、`config/` | 行情协议、共享限流、交易日历、数据校验和本地研究配置 |
| `tests/` | Python 服务、数据口径与前端交互测试 |
| `docs/`、`scripts/` | 研究过程、交接说明、训练和数据准备脚本 |

腾讯云部署和日常维护见[腾讯云运行说明](deploy/tencent-preview/README.md)。趋势指标和验证口径见[趋势观察室](docs/TREND_OBSERVATIONS.md)。原有模型实验与训练流程见[模型研究记录](docs/MODEL_RESEARCH_LOG.md)、[个股模型](docs/EQUITY_MODELS.md)和[研究交接](docs/HANDOFF.md)。

## 本地检查

```sh
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests
python3 -m http.server --bind 127.0.0.1 --directory web 8743
```

在本机打开 `http://127.0.0.1:8743` 可检查静态界面。动态行情、账号、研究助手和管理接口由腾讯云运行。浏览器轮询读取服务器已经发布的数据，采集频率与数据源实际新增时间分别记录。

公开仓库用于同步源码、模板和许可允许分发的静态资源。生产凭据、用户数据、数据库、实时数据快照及研报原件由服务器管理。
