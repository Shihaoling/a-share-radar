# 观澜 · 中国 A 股研究工作台

[网站](https://shihaoling.github.io/a-share-radar/) · [自动更新记录](https://github.com/Shihaoling/a-share-radar/actions)

研究主体是中国 A 股：沪深大盘、行业与热门主题、A 股成分股。国际信息只作为中国板块的政策、汇率、能源和供应链影响因素。项目不连接交易账户，不自动下单。

## 已实现

- 逐股预测优先：共享股票量价模型分别生成每只A股的预测，再按已知流通市值汇总31行业与去重市场研究组合；公布股票数及权重覆盖率，不冒充官方指数点位。股票可搜索、按行业筛选、分页查看。
- 券商关联行业基金：区分基金管理人由券商控股或参股，最多列3只匹配候选；市场价、单位净值、规模各用自己的日期，仅同日计算折溢价。关联不足的行业不以宽基凑数，名称匹配明确标为持仓待核验。
- 小型GRU/TCN离线训练入口、CPU试训报告和独立时间验证；神经网络候选不会自动冒充已部署主模型。完整命令、64GB/8GB设备配置和研究边界见[个股模型接手说明](docs/EQUITY_MODELS.md)。
- 6 个市场指数；主板块来自 Tushare `index_classify(src=SW2021, level=L1)` 的31个申万2021一级行业，代码与名称完全按接口返回。旧主题目录保留归档，不混进当前行业排名。
- 备用行情渠道：BaoStock、腾讯、新浪与东方财富；同日期、同标的、同复权口径的价格交叉核验，价格冲突暂停预测。主源历史优先，备用来源不覆盖同日主源价格；旧目录中的ETF代理不代替申万行业指数。
- 板块筛选、自选、指数趋势、成分股与采集后累计的总市值快照。主题重叠，市值不能加总为全市场市值。
- 官方 RSS、全球媒体 RSS、Federal Register、GDELT 和国内财经入口；原文链接、首次采集时间、来源分级、关键词产业关联及标题情绪。
- 下一次开盘的日频模型：零收益基线、Ridge、样本足够时的 HistGradientBoosting、可选 MLP(32,16)。时间顺序选择/确认窗口，达不到基线则保留基线。每次新数据到达都会重新比较，保留模型版本。
- 盘中目标为今日收盘，午休不跳到次日。缺乏有效行情时间戳或分钟样本时暂停预测；可用条件下仅显示明确标记的价格延续基线。
- 不可覆盖的预测字段、延迟结算、每日复盘、误差和方向指标、基线对比、按板块/任务分组、CSV 导出；晚到的结果回填原目标日期复盘。
- 情绪分布、盘前语气与 A 股日涨跌的描述性一致率；无人工真值时不报告“情绪分类准确率”。
- 可选 GoatCounter 访客统计；后台保持私有，无前端 API 密钥。普通访问与单独 pageview 事件分列，访客是约八小时会话估计，并非真实人数。

## 必须理解的当前边界

中文新闻使用固定版本 `yiyanghkust/finbert-tone-chinese` 在CPU推理（Apache-2.0），英文或模型不可用时明确降级为金融词典规则。每个指数和行业均展示自己的关联新闻、语气、证据与时间；无证据显示未知，不当作中性。传言默认排除，文本语气和模型置信值不等于未来上涨概率。

预测层加入量价、波动、换手率、估值、市值和新闻情绪候选特征，并保存缺失掩码。估值和情绪只有在当时确已采集且训练覆盖足够时才启用，不把今天的信息回填进过去的回测。页面区分已积累与已用于训练；当前冠军也可能仍是零收益基线。输入未变化复用模型，新增已完成数据后重新进行时间顺序验证。系统未证明具有稳定超额收益。

免费接口不保证实时和稳定。东方财富快照若只含抓取时间，明确标为 `retrieved_only`，不能作为经确认的盘中报价。市值历史从实际采集日起积累，不能通过指数曲线伪造历史市值。历史及成分分批轮转，板块目录覆盖不代表所有板块都已有同等历史深度。

2026 交易日历按上交所公告核实；未核实的年度或跨年下一交易日会暂停预测。需要在 2027 年之前补充新的官方日历。

页面默认真实模式。独立的“演示模式”只演示交互，明显标为合成数据，永不提交到训练、台账或生产采集。

## GitHub 部署

- GitHub Pages 来源设置为 **GitHub Actions**。
- `.github/workflows/update-and-publish.yml` 主分支代码更新只测试并发布缓存；仅定时或手动触发才采集、预测和保存观测，避免页面修改额外访问资讯网站。
- 完整资讯与研究更新：工作日北京时间 09:07—15:37 每半小时，以及工作日18:17的行业收盘补采、每日21:17。交易时段另外安排仅行情快照任务，与完整更新合并形成约 5 分钟的最佳努力采样；仅快照任务会跳过休市、午休和盘前盘后。GitHub 调度可能排队、延迟或跳过，不保证准点，也不是秒级实时行情。
- `--quotes-only` 主源最多两次实时接口请求；备用源最多两次请求（包含 robots.txt 探测）。主源已取得有效新行情时跳过重复备用采集；冷启动时可能先只完成一个来源。该模式不重新抓取新闻与历史日线。来源失败会冷却，不用提高请求频率补造或追赶丢失数据。
- 自动采集使用限流、缓存、robots、失败退避、HTTP 429 熔断；不绕过登录、验证码或付费墙。
- `web/data/dashboard.json` 保存完整观测与预测台账；`web/data/reviews.json` 保存每日复盘；网页优先加载精简的 `view.json`，避免重复下载后台训练缓存，`health.json` 留存逐接口与覆盖摘要。源代码和数据变更由 Git 历史保留。
- 这是公开仓库和公开网站。请勿上传持仓、账户、密钥、私人研究笔记或未获授权的数据。免费接口的代码许可不等于上游数据再分发许可；增加数据源时自行核对适用条款。

## 本机运行与小模型

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m pipeline.run
python -m http.server 8743 --directory web
```

浏览器打开 http://localhost:8743 。没有网络时可执行 `python -m pipeline.run --offline`：仅保留缓存或空状态，不生成假数据。

启用小网络：`python -m pipeline.run --enable-mlp`，或修改 `config/settings.json` 的 `enable_mlp`。它只是候选模型，仍需通过与基线的时间样本外比较。默认训练要求为 120 个训练样本 + 20 个选择窗口 + 20 个确认窗口。无需 GPU。

设置文件：

| 文件 | 用途 |
| --- | --- |
| `config/settings.json` | 模型开关、样本阈值、预测时间槽、分时采样开关、`risk_free_rate_annual` 年无风险利率假设 |
| `config/sectors.json` | 旧研究目录归档；当前主板块由申万接口决定 |
| `config/sources.json` | 来源、抓取频率、缓存、超时和预算 |
| `config/proxies.json` | 备用来源、ETF映射和每日双源核验轮转 |
| `web/data/analytics.json` | 公开统计 endpoint 与后台链接；不含任何 token |

浏览器“数据设置”仅改变本机显示偏好；下载配置后还需提交仓库，才改变云端执行。网站的刷新按钮只重新读取已发布快照，不会在访客浏览器中绕过限流采集金融网站。

## 如何看分时与量化指标

1. 在首页“市场走势”或板块详情中点击“分时”。图中仅显示**采集功能启动之后实际取得的报价时点**，不会回填合成的历史分时。不同来源分别绘线；虚线只是已采集点之间的连接，不代表中间每分钟都有行情。悬停圆点可查看来源时间、价格与提供方。有效报价时点不足两个时保留空状态。
2. 查看“行情快照”的来源时间。日线收盘值和盘中快照分别显示；`retrieved_only` 只代表采集时间，不能作为已经确认的实时报价。参考 ETF 始终标注为代理，价格单位为元，不替代板块指数点位、市值或成分股。
3. 页面每 **60 秒只重新读取已发布的静态 JSON**，刷新按钮也不会直接请求金融网站。后台约 5 分钟的调度与网络发布都有延迟，页面刷新快于后台更新时数值不变是正常现象。
4. 板块列表与详情提供供应商 PE、PB 和夏普；申万 `sw_daily.pe` 明确标注供应商PE，不能冒称TTM。财务覆盖充分时另算归母口径PE(TTM)。点击指标旁的 **?** 查看公式、当前数据口径、有效样本、覆盖率及空值原因。估值采用“市值之和 ÷ 财务量之和”，不对个股倍数简单平均。亏损与负净资产贡献保留，分母不为正时指标不适用；覆盖不足时明确标为“样本组合”。

PE/PB 为空通常是因为没有具备同一估值日、同币种和明确归母口径的成分财务，或数据存在冲突。公开快照中的动态 PE、零值、指数点位和 ETF 价格不能推算成板块 PE (TTM)。数值缺失会保留原因，不补造估值。

夏普使用最近最多 252 个、至少 60 个有效日收益样本，按 `sqrt(252) × mean(日超额收益) / sampleSTD(日超额收益)` 年化；样本标准差采用 `n−1`。未复权收盘价得到的是**价格收益指标**，不是包含分红和公司行动调整的总回报。默认年无风险利率 `2%` 只是研究假设，**不是当前市场利率**；可修改 `config/settings.json` 的 `risk_free_rate_annual`（例如 `0.02`）。ETF 代理的夏普只描述该 ETF；历史夏普不保证未来表现。

## 用户行情接口（Tushare兼容）

主力服务地址为 `https://t.xiaodefa.top/`，使用标准 HTTP POST；MCP、HTTP、Python SDK 是同一服务的访问方式，不计为三个独立数据源。该服务不是 Tushare 官方域名，兼容协议不代表已核实数据上游、免费额度或服务保证。

在仓库 **Settings → Secrets and variables → Actions → New repository secret** 中添加 `STOCK_API_TOKEN`。令牌仅注入采集步骤的环境变量；不得写入配置、代码、网页、日志或工作流输入。未配置密钥时显示待配置，现有数据源照常工作。本机可将同名环境变量设置后运行采集器，不需要额外安装 SDK。

首次验证可在原有工作流手动运行时仅勾选 `stock_api_only`，或本机执行 `python -m pipeline.run --stock-api-only`。此模式复用其他来源缓存，不额外抓取资讯或分时行情；仍只保留一个工作流。

主源接入 `index_classify`、`index_member_all`、`sw_daily`、`index_daily`、`daily_basic`、`trade_cal`；可选 `rt_idx_k`、`rt_sw_k` 和 `news` 按实际权限启用。行业展示完整成分映射和总市值前10股票，优先显示当日确认收盘；未取得当日数据时明确显示实际日期。已确认的当日收盘优先于盘后未确认快照，不再人为等到18:30。

2026-11-16能力检查中，行业分类、成分、行业日线、每日估值与当日指数日线成功；该令牌的两个实时接口和财联社新闻接口权限被拒绝。拒绝后按接口冷却24小时，使用已有行情备用源和新闻来源，不重复撞限。SW行业实时不可用时不把个股或ETF分时伪装成行业分时。数据设置展示逐接口状态。

主源每轮最多12次请求、间隔至少3秒、无自动重试；指数、成分和行业历史缓存轮转。429或认证失败触发全局停止，单接口拒绝只暂停对应接口。首次可手动选择 `bootstrap_rounds=8` 或执行 `python -m pipeline.run --bootstrap-rounds 8`，最多8轮，每轮仍最多12次请求，后续轮次复用其他来源缓存；达到覆盖、触发冷却或没有进展时提前结束。平时无需反复补齐。

`daily_basic.total_mv` 和 `sw_daily.total_mv` 从万元换算为元；申万日线成交量单位为万股。服务报告的PE/PB单独保留为供应商指标，不冒充归母利润或权益。MCP、HTTP、SDK不计为三个独立行情来源，兼容服务的真实额度与上游需以服务方说明为准。

情绪推理依赖见 `requirements-sentiment.txt`，GitHub完整刷新会安装CPU版PyTorch并缓存固定模型revision。推理不使用远程自定义代码，不自动训练未知新闻标签；新情绪观测按首次可见时间积累后才有资格进入价格模型验证。

## 最新模型的扩展路线

可把 Chronos-2 等公开时序基础模型作为额外挑战模型，本项目尚未下载或启用其权重。通用时序基准成绩不能替代 A 股样本外验证。大语言模型适合辅助事件抽取，不应直接生成看似精确的涨跌概率。先积累带首次可见时间的新闻样本、真实预测与标签，再评估情绪/事件特征的增益。
